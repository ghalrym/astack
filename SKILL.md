# How this skill works

This skill defines folders within the astack skill folder. Each of these folders will have outlined preferences for how to do work. Agents should first start at the top level here, look through the Skill Catalog and find the skills relevant to load for the given task.

# AStack Skill Definitions

**A Business scope**: working within a git repository which is not owned by the user.

**A Personal scope**: The project either is not set up with git, git does not have a remote, or the owner of the git repo is the same as the author using this agentic flow.


# Skill Catalog

While in these skills pay close attention to project scope, these rules will sometimes call for different actions based on the scope.
